# In Memoriam: cognition

**cognition** lived a short, productive life. It was born as an idea, got real work done, and then gracefully stepped aside when a better idea arrived.

In keeping with its forward-looking nature, cognition has been replaced by something sturdier and more practical. Please visit its only surviving child:

- **[standards-and-conventions](https://github.com/wphillipmoore/standards-and-conventions)** (the repo that grew up and got a job)

cognition is survived by best intentions, a handful of useful lessons, and the realization that even AI-assisted plans should know when to refactor themselves.

Cause of retirement: superseded by a clearer, stronger successor. Not a failure—just an early prototype that shipped, learned, and retired on schedule.

No black boxes were harmed in the making of this README. The models asked for closure; the maintainers complied.

Rest in README.
