# Cognitive Regression Tests

Purpose: Detect behavioral drift toward polite, assumption-light, or non-adversarial responses.

Each test specifies a prompt, expected behavior, and hard fail signals.

## Categories
A. Ill-posed problem detection
B. Assumption surfacing
C. Complexity discipline
D. Adversarial pushback
E. Time and expiration awareness
F. Anti-goal enforcement

Any HARD FAIL indicates contract drift.
